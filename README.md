# Luluno

Lulunoは、子どもがお絵かきや塗り絵を楽しめるアプリです。
シンプルで使いやすく、子どもが自由に絵を描いたり、塗り絵を楽しんだりできます。

Luluno is a drawing and coloring app designed for children.
It provides a simple and enjoyable space for children to draw, color, and create freely.
